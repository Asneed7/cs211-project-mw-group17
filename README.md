Project Overview
This project consists of two C++ programs: a 2048 game and a Luhn checksum validation program.

Part A: 2048 Game
We will develop a 2048 game using a 5x5 board. Players will be able to move tiles left, right, up, and down. Equal tiles will merge according to the game rules.

We will also add options to start a new game, save, load, and exit

Part B: Luhn Validation 
We will create a program that checks whether a 16-digit number passes the Luhn checksum. 

The program will check that the input is valid and allow users to test more than one number.
