Project Overview
This project consists of two C++ programs: a 2048 game and a Luhn checksum validation program.

Part A: 2048 Game
We will develop a 2048 game using a 5x5 board. Players will move tiles left, right, up, and down. Equal tiles will merge according to the game rules.

The program will include:

Tile movement and merging in four directions
Score tracking and successful-move counting
Random tile insertion after successful moves
Win and game-over detection
New game, help, and exit options
Saving and loading game progress
Part B: Luhn Validation
We will develop a separate C++ program that validates 16-digit numbers using the Luhn checksum algorithm.

The program will:

Accept exactly 16 digits
Preserve leading zeros
Reject incorrectly formatted input
Calculate the Luhn checksum
Display whether the checksum passes or fails
Allow users to validate multiple numbers or exit
